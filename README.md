## 🚨 Why SafeRoute Exists

Bangladesh is facing its worst crime surge in 6 years.

| Crime | 2025 Statistics |
|---|---|
| Snatching cases | +37% vs previous year |
| Robbery cases | +43% increase |
| Murders (Jan 2025 alone) | 294 — highest in 6 years |
| Violence against women | 21,936 cases in 2025 |
| Total cases filed | 1,81,737 in 2025 |

The real problem: **most crimes go unreported.** Victims fear police harassment, complicated procedures, and being ignored for "small" crimes. Criminals know this — and use it.

**SafeRoute breaks this cycle.** When every person can report instantly, share with their community, and alert family in danger — criminals lose their biggest advantage: invisibility.

## ✨ Features

### 🔴 Live Crime Feed
Real-time alerts from your area. Every new report appears instantly for all users — no refresh needed. Severity levels (High / Medium / Low) help you prioritise what to avoid.

### 🗺️ Interactive Crime Map
Powered by **OpenStreetMap** — real streets of Bangladesh. Every crime report is pinned to its exact GPS location. Filter by crime type, navigate to Dhaka or Chittagong, and see your own blue dot live on the map.

### 📢 Report an Incident
Submit a crime report in under 30 seconds:
- Choose crime type (Snatching, Robbery, Theft, Harassment, Violence, Phone Theft, Bus Crime)
- Capture your GPS location with one tap — or pick the exact spot on the map
- Add photo evidence directly from your camera or gallery
- Report anonymously — your identity stays hidden

### 🆘 Emergency SOS
One tap when you are in danger:
- 📞 **Direct call to 999** — Bangladesh Police emergency
- 💬 **WhatsApp SOS to family** — pre-written message with your live GPS coordinates
- 📱 **SMS to all saved contacts** — reaches everyone at once
- 🗺️ **Open in Google Maps** — share your exact location

### ✅ Community Verification
Every report can be voted **True ✓** or **False 🚩** by the community. Reports with multiple false flags go under admin review automatically. False reporters get permanently banned.

### 👨‍👩‍👧 Emergency Contacts
Save up to 5 family members (name + phone). One tap calls them directly. SOS automatically sends to your saved contacts — no need to search for numbers in an emergency.

### 📊 Crime Hotspot Statistics
See which areas are most dangerous, which crime types are most common, and track how reports are trending over time. Useful for both citizens and law enforcement.

### 🔐 Admin Panel
For verified administrators:
- Verify, flag, or delete reports
- Block users who submit false reports
- Restore wrongly blocked users
- Full user management

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| Vanilla JavaScript | Core app logic — zero frameworks |
| HTML5 Canvas + File API | Photo evidence capture and preview |
| Leaflet.js v1.9.4 | Interactive OpenStreetMap integration |
| OpenStreetMap + CartoDB | Real Bangladesh map tiles (free forever) |
| Claude AI API (Anthropic) | Intelligent real-time database |
| Web Geolocation API | Live GPS location capture |
| Web Share API | Native share sheet integration |
| localStorage | Emergency contacts stored privately on device |

## 🔒 Privacy

- No photo is ever sent to any external server without your consent
- Anonymous reporting hides your identity completely
- Emergency contacts are stored only on your own device
- Location data is used only when you actively submit a report or trigger SOS
